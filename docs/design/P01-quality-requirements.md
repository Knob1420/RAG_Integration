# P01 解析质量要求（quality requirements）

> TASK-P01-001 产物。定义：质量检查项与阈值、解析状态机、进索引的硬门槛。P01-002 实现检查器，P01-005 出质量报告。

## 解析状态机（parse_status）

```
NOT_STARTED ──→ IN_PROGRESS ──→ DONE            （质量门全过，允许进索引）
                    │
                    ├──→ PENDING_REVIEW          （成功但存疑，人工复核；不进索引）
                    ├──→ PENDING_OCR → IN_PROGRESS（R3 专属中间态，OCR 队列）
                    └──→ FAILED                  （解析器报错/修复失败；不进索引）
```

规则：
1. 状态以 **source（文件）级**流转；R2/R8 允许**页级/sheet 级**子状态（部分可用部分挂起）；
2. FAILED 必附原始错误信息（不含正文）；
3. 状态流转全部落日志（时间、路由、原因码），质量报告的数据源。

## 质量检查项（按路由）

| 检查 | R1/R2 | R3 OCR | R4/R5/R6 docx | R7/R8 xlsx | 阈值 |
|------|-------|--------|---------------|------------|------|
| 文本量下限 | ✓ 每页 | ✓ 每页密度 vs 图幅 | ✓ 全文 vs 同类均值 | — | 文字页 ≥50 chars/页；OCR 页 ≥ 密度预期 |
| cjk_ratio | ✓ ≥0.2 | ✓ ≥0.2 | ✓ ≥0.2（.doc 转换后重点） | — | <0.2 → PENDING_REVIEW |
| 乱码率（\ufffd 等） | ✓ | ✓ | ✓ | — | <1% |
| 结构守恒 | 表格行列 vs pdfplumber | OCR 表格行列 vs 版面线框 | 表格解析行数=源行数；标题非空率 | **单元格守恒**：输出=非空输入（合并展开计入） | 100% |
| 溯源完整性 | ✓ | ✓ | ✓ | ✓ | source_id+位置字段缺失 = 阻断 |
| 版本漂移 | 重跑文本量与前次差 >30% 告警 | 同 | 同 | 单元格数差 >10% 告警 | 告警→人工 |
| 空文本阻断 | ✓ | ✓ | ✓ | ✓ | 任何空/近空 Element 不得产出 |

## 进索引硬门槛（任一不过即阻断）

1. parse_status = DONE；
2. 每个	Element 带 source_id + 位置字段 + extraction_mode + 解析器版本；
3. 无空文本 Element（扫描页/空页必须显式 omitted 而非空串）；
4. 表格 Element 必带表头（多行表头已展开）；
5. 单元格/行列守恒通过；
6. content_sha256 已计算（主副本判定前置，P01-003）。

## 阻断类失败（必须阻止进索引）

| 失败 | 原因 |
|------|------|
| 扫描页空文本 | 学习门红线：空文本入索引=检索永远命中不了还占库，且掩盖"读不了"事实 |
| .doc 转换丢中文（cjk<0.2） | 静默丢内容的"成功"比失败更危险 |
| OCR 乱码输出 | 同上 |
| 无表头表格行 | 行数据失去语义（哪列是什么），检索命中也无法判读 |
| 无 source_id 的 Element | 溯源链断裂，删除传播失效（DATA_GOVERNANCE 硬要求） |

## 质量验收抽样方案（P01-005 用）

- 每路由抽 ≥2 个 source（golden sample 优先）；
- 人工比对项：章节标题正确性、表格行列还原、正文完整性抽查（首/中/尾各 1 段）、位置回链可打开到正确页/sheet；
- 溯源抽查：随机 20 个 Element 反查原始位置，100% 正确才通过；
- 报告不含正文，只含计数与判定。
