# 术语表（GLOSSARY）

> 工程化定义，服务于本仓库的统一语言。定义与本表冲突的文档应修正。

## 数据与溯源

- **Source（原始资料）**：用户提供的、有合法使用权的航天资料文件本体（PDF/文档/表格等）。是项目一切结论的最高证据来源，存放于仓库外，以 source_id 标识。
- **Document（文档）**：一份 Source 经解析后得到的结构化单元，携带格式、标题、版本、安全等级等元数据，并回链 source_id。
- **Chunk（块）**：Document 切分后的最小检索单元（文本段、表格行组、图注等），必须携带回链到原始页码/位置的 provenance。
- **Evidence（证据）**：用于支撑某条回答或陈述的一个或多个 Chunk 及其 provenance。无 Evidence 支撑的陈述不得出现在答案或 Wiki 中。
- **Provenance（溯源）**：从任何派生数据回到原始 Source 具体位置的完整链路（source_id + 页码/坐标 + 解析器版本）。

## 检索与生成

- **RAG（Retrieval-Augmented Generation）**：先检索证据、再基于证据生成回答的架构。本项目要求回答中的每条陈述均可回链 Evidence。
- **Hybrid Retrieval（混合检索）**：关键词检索（BM25）与语义检索（Embedding）并行、按策略融合的检索方式。
- **Reranker（重排器）**：对召回结果做精排的模型（通常为交叉编码器），在 top-k 层面提升证据相关性。

## 知识图谱

- **Entity（实体）**：资料中可辨识的事物（型号、部件、机构、任务、参数等），有唯一标识并回链 source_id。
- **Relation（关系）**：两个实体间有类型的边（如"装配于""依据""修订"），每条边必须记录支撑它的 Evidence。
- **Entity Resolution（实体消歧/链接）**：把不同写法/别名指向同一实体的过程，决定图是否碎片化。
- **Knowledge Graph（知识图谱）**：实体与关系的集合，侧重领域知识本身的表示。
- **Traceability Graph（工程追溯图）**：本项目特指叠加了工程语义（版本演进、依据关系、装配/依赖结构）的知识图谱，服务于"从哪来、改了什么、影响什么"类问题。
- **GraphRAG**：以图为检索媒介的 RAG 方式，通过图遍历而非仅向量/关键词获取证据。
- **Local Search（局部搜索）**：从问题相关实体出发的邻域图遍历检索，适合具体/单点问题。
- **Global Search（全局搜索）**：跨社区/全图汇总式的图检索，适合综述、总结类问题。

## Wiki 与记忆

- **LLM Wiki**：由 LLM 基于 Evidence 生成、每条陈述带引用、可增量更新并经人工审核的领域知识页面。Wiki 是沉淀层，不是 ground truth，与领域知识库（原始资料+规范化数据）严格区分。
- **Working Memory（工作记忆）**：当前任务执行期间的临时上下文（已检索内容、中间结论），任务结束即弃。
- **Semantic Memory（语义记忆）**：从交互中沉淀的领域事实与偏好（用户术语习惯、常用资料），跨会话保留，受 Memory policy 管控。
- **Episodic Memory（情景记忆）**：具体历史交互与任务过程的记录（何时、问了什么、结果如何）。
- **Procedural Memory（程序记忆）**：沉淀下来的操作经验与流程（如何查某类参数、常见修复步骤）。
- **Task State（任务状态）**：多步任务的显式状态机（分解、检索、汇总、拒答等阶段），保证可恢复与可审计。
- **领域知识库 / LLM Wiki / Agent Memory 的区分**：知识库=原始证据的规范化（唯一 ground truth）；Wiki=面向人读的证据摘要沉淀（须回链）；Memory=关于用户、任务和经验的运行时信息（不属于领域知识，绝不反哺为事实依据）。

## 评测

- **Ground Truth（真值）**：来自原始资料、经人工确认的权威答案或证据。LLM 生成内容永远不是 ground truth。
- **Gold Evidence（金标准证据）**：评测集中人工标注的、能支撑标准答案的 Chunk 集合，用于计算检索指标。
- **Silver Label（银标准）**：由模型或弱规则生成、未经人工逐条确认的标注，只用于辅助分析，不用于阶段验收。
- **Answerability（可回答性）**：判定当前资料范围内某问题是否具备充分证据作答的属性；不可回答必须显式拒答，不得编造。
- **Unsupported Claim（无支撑陈述）**：答案或 Wiki 中无法回链到 Evidence 的陈述，视为质量缺陷，评测中扣分并要求清零或显式标注。
