### 门校准记录（全量数据驱动）

1. **扫描页覆盖率阈值 85% → 70%**：实测扫描页图幅含页边距，覆盖率 0.74–0.81；4 份记录表首跑全被判 empty。页无文字 + 单张主导图即扫描页，0.70 起无歧义。
2. **cjk 门双口径**：表格主导文档（xlsx/履历书/IDS）数字与编号稀释分母，raw cjk 0.117–0.198 但"仅字母"口径 0.29–0.71。校准为 raw 与 letters **任一** ≥0.2 即过；所防失效模式（antiword 丢中文 raw≈0.06）两口径皆低仍被拦截。此即 P01-001 遗留的 GS-08 cjk≈0.17 校准问题，已解。
3. **xlsx 合并标题行 + 列裁剪**（验收走查中发现）：Sheet2 首行是横跨 6 列的合并说明行，合并展开后整行同值+尾部空白列，被误判为"多行表头"，真表头被拼接污染（每列 header 变成"长说明/字段名"）。修复：① 表区块先裁剪到有值列区间；② 整行同值视为合并标题行 → 产单条 key_value（merged_title 标记），表头取下一行，弹出后再裁一次列。修复期间漂移门正确触发（交付清单两份 chars±47% 挂复核），确认变更为预期后复跑归零——漂移检测机制首次实战验证有效。
4. **表题行污染表头（四格式拉齐，原已知缺口 3 正式解决）**：xlsx/docx/pdf 原生/OCR 四路统一规则——表首行"仅一格非空（colspan 表题）或整行同值（合并痕迹）"→ 产单条 key_value（merged_title），表头取下一行；OCR 路支持连续标题行（记录表每张表 2-3 行表题/检查时间/检查人员）。修复后记录表表 1 表头从 `['附表1 物理特性检查表']` 变为真实列头 `['序号','测试项目','判据','测试结果','符合性']`，4 份记录表共产 32 条标题 kv。
