# P01 Golden Sample 要求与清单

> TASK-P01-001 产物。Golden Sample = **解析回归测试基准**：验证解析器输出结构与溯源的正确性、防回归；**不是** RAG 问答的 Ground Truth（那是 P03 评测集的职责，两者严格分开）。

## Golden Sample 验证什么 / 不验证什么

**验证**：
1. 结构还原：标题层级数、表格数/行列、sheet 数、页数与登记的期望值一致；
2. 溯源：每个 Element 回链到正确 source_id + 页/sheet/行；
3. 路由正确：每份样本走到预期路由（extraction_mode 断言）；
4. 质量门：阈值项（cjk/乱码/守恒）在阈值内；
5. 防回归：解析器改动后重跑，特征值漂移超限即报警。

**不验证**：
- 问答答案对错（P03 评测集，21 问）；
- 语义质量（摘要是否通顺——解析只管保真，不管语义）；
- 图片内容（首版不抽，只登记占位）。

## 选样原则

每条路由 ≥2 份；每类结构风险（WPS/扫描/混合/多行表头/转换链）至少 1 份代表；文件小优先（回归测试要快）；含 1 组近重复对（主副本判同的回归对象）。

## 清单

见 `P01-golden-sample-manifest.csv`（14 份，覆盖 R1–R8 全路由 + 近重复对）。

## 维护规则

1. 期望特征值（expected_*）来自 P00 实测；P01-002 首次解析后复核并固化；
2. 解析器版本变更 → golden sample 全量重跑 → 漂移超限须解释；
3. 新增结构风险类型 → 增补样本，不改旧样本期望值（除非人工确认原值有误）。
