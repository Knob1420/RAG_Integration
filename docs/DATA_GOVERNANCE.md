# 数据治理（DATA_GOVERNANCE）

> 本文件是数据安全与数据边界的一级约束，任何阶段不得违反。文档间冲突的优先级见 WORKFLOW.md。

## 资料分级

| 等级 | 定义 | 可否进入本仓库 | 可否发送到外部模型 API |
|------|------|----------------|------------------------|
| 公开 | 已公开发布的资料 | 摘要/元数据可 | 可 |
| 内部可用 | 内部使用、不含敏感细节 | 仅元数据与 source_id | 需用户确认 |
| 受限 | 含技术细节或专有信息 | 仅元数据与 source_id | 默认禁止，需用户明确批准 |
| 禁止外发 | 明确不得外传的资料 | 仅元数据与 source_id | 禁止 |

- 每份登记资料必须在资料清单（docs/reports/P00-data-inventory.md）中标注等级；
- 等级由用户确定，GLM/Codex 不得自行降级；
- 未定级的资料一律按「受限」处理。

## 不能发送到外部模型的内容

1. 「禁止外发」和「受限」级资料的正文、表格内容、图片；
2. 含型号、参数、编号等敏感细节的 Chunk 原文；
3. 未脱敏的评测集样本；
4. 任何包含上述内容的日志片段、错误信息、调试输出。

## 数据边界

| 数据类别 | 存放位置 | 说明 |
|----------|----------|------|
| 原始资料 | 仓库外的专用目录（路径登记在资料清单） | 不进入普通代码仓库 |
| 规范化数据（Document/Chunk） | 本地数据目录（不入仓库） | 每 Chunk 带 source_id 与位置 |
| 索引（BM25/向量/图） | 本地数据目录（不入仓库） | 可从规范化数据重建 |
| 日志 | 本地 logs 目录 | 不得记录敏感原文 |
| 评测集 | 仓库（必须脱敏） | 仅保留问题、source_id 引用和标注 |
| 派生报告/Wiki | 仓库（引用仅用 source_id） | 不复制原文段落（必要摘录需经用户确认） |

## 删除传播

删除某份资料后，以下派生数据必须一并清理：

1. 该资料的规范化 Document/Chunk；
2. BM25 索引中的对应项；
3. 向量索引中的对应向量；
4. 知识图谱中由该资料唯一支撑的实体/关系（多源支撑的需降级并更新 provenance）；
5. 评测集中引用该资料的样本；
6. Wiki 页面中仅由该资料支撑的陈述（标记失效或删除）；
7. Memory 中源自该资料的条目；
8. 日志不做回溯清理，但不得含原文（见日志规则）。

清理的正确性通过 source_id 反查验证：删除后全链路检索不到该资料的任何派生项。

## 凭证与敏感路径

- API Key、密码、Token、证书不得提交到仓库；
- 原始资料的本地绝对路径视为敏感信息，仓库内只登记相对标识或代号；
- 使用环境变量或仓库外配置文件管理凭证，配置模板入仓库时必须无真实值。

## 日志规则

- 日志不得记录敏感资料原文（含 Chunk 全文、表格内容）；
- 日志只记录 source_id、长度、哈希、检索得分等非内容字段；
- 调试需要查看内容时，仅在本地终端临时输出，不写入日志文件。

## 溯源要求

- 所有派生记录（Chunk、索引项、图实体/关系、评测样本、Wiki 陈述、Memory 条目）必须保留 **source_id**；
- source_id 规范在 P01 定义并写入 ADR，一经定义不得无 ADR 变更；
- 任何无法回链 source_id 的派生数据视为脏数据，不得进入下游。

## 版本记录要求

| 版本类型 | 记录内容 | 记录位置 |
|----------|----------|----------|
| 数据版本 | 资料集合的变更（新增/删除/修订） | 资料清单（含变更日志） |
| 解析器版本 | 解析器代码版本与已知缺陷 | 解析器版本文件/ADR |
| 索引版本 | 索引构建所用的数据版本 + 解析器版本 + 配置 | 索引目录元数据 |
| 模型版本 | Embedding/Reranker/LLM 的模型标识 | 选型 ADR 与运行日志 |

- 任何评测结果必须同时记录上述四类版本，否则不可用于阶段对比；
- 索引与构建它的数据/解析器版本不一致时必须重建。

## 原始资料不进入普通代码仓库的建议

1. 原始资料存放于仓库外的专用目录，路径不提交；
2. 仓库内以资料清单 + source_id 引用；
3. 如需版本管理原始资料，使用独立的受限访问仓库或存储，不与本代码仓库混放；
4. 备份与同步策略由用户决定。
