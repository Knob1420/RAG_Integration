# 领域关系图（domain-map）

> P00-L 第二步产物。"资料类型"表为用户自填；"资料之间的关系"骨架取自用户手写链，由 GLM 整理成表并补充；其余小节 GLM 代写（2026-09-03），复盘按代写节处理。

| 资料类型 | 目的（我的话） |

## 资料之间的关系

用户手写链（骨架）：技术要求 → IDS表 → 方案设计报告 → 环境试验大纲 → 验收测试细则 → 总结报告 → 说明书/履历书/证明书

整理成表（每条标显式/推测；日期取自文件名/落款，可用 manifest 核对）：

| 关系 | 显式/推测 | 证据 | 检索可用性 |
|------|-----------|------|------------|
| 会议纪要 → 方案设计（建议驱动选型迭代，如 CPU 2核→4核） | 推测（纪要有建议句，方案无"采纳"字样；且方案落款可早于会议） | 纪要第（9）条 + Z0/Z1 器件表比对（Q-021/Q-040 学习卡） | 高（时间过滤+对象校验后可查） |
| 方案设计 → IDS 表（方案定了对外接口，IDS 细化到接点） | 推测（时间顺序支持：总体方案 2024-03 → IDS 签署 2024-09） | 两文档接口章节同构 | 中 |
| 环境试验大纲 → 总结报告（规定 vs 执行） | **显式**（大纲被总结"引用文件"节引用） | 总结报告"引用文件"节 | 高 |
| 验收测试细则 → 测试记录 → 总结报告结论（Q-011/014 证据链） | 显式（结论句可回链） | 老炼结果 8 列表、总结结论句 | 高 |
| 总结报告 / 测试记录 → 履历书/证明书（过程证据汇总为交付证明） | 推测（Z0102 编号贯穿交付清单↔证明书↔履历书） | 交付清单"生产编号"列 | 高（编号精确检索） |
| 遥测汇总表 内部：修改记录 sheet ↔ 各协议 sheet 版本演进 | 显式（sheet 内"最后修订时间"字段） | Q-006 学习卡 | 高 |
| 同名文件跨目录（工作版 ↔ 外发盖章版）副本关系 | 显式（同名+同尺寸+近内容，哈希不同） | manifest 5 组同名记录 | 高（主副本口径已定） |
| 程控时间表 8.28→8.31→9.1→9.2 版本链 | 显式（文件名日期 + 表内北京时间列） | Q-028 学习卡 | 高 |
| 方案设计 → 说明书（设计定型后写使用文档，模块配对：计算/电源各一套） | 推测（两模块各有方案报告+说明书，版本均 V1.0） | 文件名成对 | 中 |

两条并行链注意：**X100 计算模块**和**电源模块**各有自己的 方案设计/说明书/IDS/证明书，链是双轨的，不是单链。

## 常见实体

- 单机/模块：智加X100计算模块、配套电源模块、（Z0 架构中的）预处理模块
- 器件：CPU FT2000-4（飞腾）、GPU MRC-V100-3024（天数智芯）、CPLD A3P600/A3P250、FPGA V7（复旦微 JFM7VX690T）、DDR4（MICRON）、SSD/mSATA 盘
- 接口/总线：CAN（1主1备）、RS422×3、万兆网 10GBase-SR、GPIO、J30J 系列连接器
- 系统：3D打印卫星（主星）、智算载荷、星务机
- 试验：验收级随机振动、热真空、热摸底、老炼、电测、程控业务
- 软件：UBOOT、CPU(linux) 及业务软件（版本控制表管理）

## 版本和状态线索

1. 文件名内嵌版本（技术说明书V1.0、IDS表_20240924_签署、终稿_20250120）——最强线索；
2. IDS 修订表（修订前/后版本号/修订日期列）——文档内显式版本史；
3. 遥测表各 sheet"最后修订时间" + 修改记录 sheet——表内版本字段（≠文件 mtime，Q-006 教训）；
4. 软件版本控制表（提测版本/版本号两列并列）——注意两列是不同概念；
5. filesystem_mtime（2024-03~2025-09）——弱线索，只作排序参考，不是 document_version；
6. 状态词（计划/完成/通过/待确认/建议/推测）——结论性表述需引用原文，不得推断。
