# RAG 问题地图（retrieval-problem-map）

| 问题 | 需要的知识 | 主要难点 | 第一选择 | 是否可能需要图 |
|------|-----------|----------|----------|----------------|
| Q-006 协议最后修订时间 | 单一表格字段事实 | 字段在表头区非正文；多 sheet 同名歧义 | 精确/Hybrid（sheet 级 metadata） | 否 |
| Q-014 老炼遍历结论 | 测试结构与状态 | 条件/结果/结论同行同表；多轮同名 | 类型化 RAG（按测试项行组切分） | 否 |

| Q-037 扫描件可否提取 | 证据可用性自察 | 检索为空≠无证据；防他文顶替 | RAG + parse_status 分流 + 拒答 | 否 |

## 三条结论（P02/P04/P05 的边界）

1. **不是所有问题都需要 GraphRAG**：6 问中 3 问（006/014/037）用 结构化解析 + metadata + 拒答 就够，建图无增益；
2. **不是所有问题都适合向量检索**：Q-028 的差异比对、Q-006 的字段查找，语义相似度反而引入歧义——精确匹配和结构化 diff 是主力；
3. **不是所有问题都需要 LLM**：Q-006/Q-014 若 P01 结构化做到位，规则即可出答案；LLM 的价值在 Q-021/Q-040 的跨文推理与 Q-037 的拒答表述。

## 每题证据去向

| 问题 | 要找什么证据 | 证据通常在哪 | 为什么简单检索可能失败 |
