# 知识地图（KNOWLEDGE_MAP）

> 按优先级分三级。每项包含：为什么需要 / 建议学习资料类型 / 对应项目实验 / 掌握证明。
> 「掌握证明」= 仓库内可查的证据（代码、测试、报告），不是自我声明。

## 一、必须掌握（P00–P05 期间陆续达成）

### 1. 信息检索
- **为什么需要**：整个系统建立在"找得到证据"之上，检索是一切链路的地基。
- **建议学习资料类型**：IR 教科书相关章节（倒排索引、TF-IDF、评测）、检索库官方文档。
- **对应项目实验**：P02 BM25 索引构建与 top-k 命中检查。
- **掌握证明**：P02 检索代码 + 命中检查记录。

### 2. BM25
- **为什么需要**：关键词精确匹配（型号、编号、参数）是航天资料的刚需，且是最强基线。
- **建议学习资料类型**：BM25 原论文 + 所用检索库文档。
- **对应项目实验**：P02 BM25 基线；P03 指标化。
- **掌握证明**：能解释参数（k1、b）对结果的影响，并有调参对比记录。

### 3. Embedding
- **为什么需要**：同义改写、自然语言问法需要语义检索补足字面匹配。
- **建议学习资料类型**：句向量模型文档、相似度度量基础。
- **对应项目实验**：P02 向量索引；P04 Embedding 对比选型 ADR。
- **掌握证明**：选型 ADR + 对比实验数据。

### 4. Hybrid Retrieval
- **为什么需要**：航天问题常同时含精确编号和语义描述，单一检索必有盲区。
- **建议学习资料类型**：混合检索融合策略（加权/RRF）文章与实践。
- **对应项目实验**：P02 初步融合；P04 正式消融。
- **掌握证明**：融合 vs 单路检索的对比报告。

### 5. Reranker
- **为什么需要**：召回粗排后需精排，直接决定 top-k 证据质量。
- **建议学习资料类型**：交叉编码器 vs 双塔的解释文章、rerank 库文档。
- **对应项目实验**：P04 Reranker 消融实验。
- **掌握证明**：消融报告显示指标变化与延迟代价。

### 6. RAG 评测
- **为什么需要**：没有评测的优化是盲飞；阶段门的通过标准全靠指标。
- **建议学习资料类型**：RAGAS 类评测框架思路、检索/生成指标定义。
- **对应项目实验**：P03 评测体系建设全程。
- **掌握证明**：评测集 + 可复现评测脚本 + 基线报告。

### 7. 文档解析
- **为什么需要**：真实航天资料是 PDF/表格/图文混合体，解析质量决定上限。
- **建议学习资料类型**：各格式解析库文档、表格抽取实践。
- **对应项目实验**：P01 全部。
- **掌握证明**：解析质量抽样报告。

### 8. 元数据和 provenance
- **为什么需要**：引用回链、版本过滤、删除传播全部依赖元数据链路。
- **建议学习资料类型**：数据血缘/provenance 概念文章、W3C PROV 概览。
- **对应项目实验**：P01 数据模型设计。
- **掌握证明**：source_id 规范文档 + 100% 回链抽查通过。

### 9. 结构化输出
- **为什么需要**：解析结果、Wiki、Memory 都需要机器可校验的结构。
- **建议学习资料类型**：JSON Schema、结构化抽取实践。
- **对应项目实验**：P01 规范化输出；P06 Wiki 页面 schema。
- **掌握证明**：带 schema 校验的输出 + 校验测试。

### 10. 知识图谱建模
- **为什么需要**：追溯图需要先有本体设计，否则抽取无从下手。
- **建议学习资料类型**：本体设计入门、属性图模型文档。
- **对应项目实验**：P05 schema 设计 ADR。
- **掌握证明**：schema ADR + 按 schema 构建的图数据。

### 11. 实体链接
- **为什么需要**：同一部件/型号在资料中有多称呼，不消歧则图碎片化。
- **建议学习资料类型**：实体链接/消歧入门文章。
- **对应项目实验**：P05 实体消歧管线。
- **掌握证明**：消歧抽样核对报告。

### 12. 图遍历
- **为什么需要**：跨文档追溯本质是图上的多跳查询。
- **建议学习资料类型**：图查询语言教程（所用图库的查询语法）。
- **对应项目实验**：P05 遍历查询与 Local Search。
- **掌握证明**：跨文档问题的图查询结果与回链证据。

### 13. Agent 状态
- **为什么需要**：多步任务（分解、检索、汇总）需要显式状态管理才能可靠。
- **建议学习资料类型**：Agent/状态机设计文章。
- **对应项目实验**：P07 Task State 模型。
- **掌握证明**：状态模型代码 + 状态流转测试。

### 14. Memory policy
- **为什么需要**：无政策的记忆会污染、过期、越权。
- **建议学习资料类型**：记忆分型（working/semantic/episodic/procedural）文章、遗忘策略实践。
- **对应项目实验**：P07 policy 设计与行为测试。
- **掌握证明**：policy 文档 + 删除/衰减/权限测试通过记录。

### 15. 数据库和 API 基础
- **为什么需要**：索引、图、Memory 最终都要落库并对外提供统一入口。
- **建议学习资料类型**：所选数据库文档、REST API 设计规范。
- **对应项目实验**：P08 集成。
- **掌握证明**：可运行的集成入口 + 部署文档。

### 16. 测试和可观测性
- **为什么需要**：阶段门验收依赖可复现测试；线上问题依赖日志与指标定位。
- **建议学习资料类型**：测试金字塔、结构化日志/指标实践。
- **对应项目实验**：贯穿全程；P08 收口。
- **掌握证明**：测试套件 + 可观测性规范与样例日志。

## 二、需要熟练（P04–P08 期间按需深入）

### 17. Query Rewrite
- **为什么需要**：用户口语问法与资料术语不一致，改写显著提升召回。
- **建议学习资料类型**：查询改写实践文章。
- **对应项目实验**：P04 改写消融。
- **掌握证明**：改写前后对比数据。

### 18. Query Decomposition
- **为什么需要**：跨文档复合问题必须拆成子问题分别取证。
- **建议学习资料类型**：问题分解实践、任务分解模式。
- **对应项目实验**：P04 分解路由；P05 跨文档问题。
- **掌握证明**：复合问题的分解执行记录与结果。

### 19. 表格检索
- **为什么需要**：参数、规格大量存在于表格，纯文本切块会破坏表格结构。
- **建议学习资料类型**：表格解析与检索实践。
- **对应项目实验**：P01 表格规范化；P04 表格专用链路。
- **掌握证明**：表格类问题命中率数据。

### 20. 版本过滤
- **为什么需要**：同一文件常有多个版本/修订，不过滤会新旧混答。
- **建议学习资料类型**：文档版本管理实践。
- **对应项目实验**：P01 元数据设计；P04 版本过滤策略。
- **掌握证明**：多版本资料的问答不混用新旧版本。

### 21. 增量更新
- **为什么需要**：资料会更新，全量重建不可持续（Wiki 与索引同理）。
- **建议学习资料类型**：增量索引/知识库更新实践。
- **对应项目实验**：P06 Wiki 增量更新。
- **掌握证明**：增量 vs 全量的等价性检查记录。

### 22. 权限和数据删除
- **为什么需要**：资料有分级，删除须传播到所有派生数据，这是治理硬要求。
- **建议学习资料类型**：数据删除传播（含向量库删除）、访问控制基础。
- **对应项目实验**：P01 source_id 设计；P07 删除测试。
- **掌握证明**：删除某资料后全链路无残留的验证记录。

### 23. Prompt Injection 防御
- **为什么需要**：资料正文会进入提示词，恶意或误导内容可能劫持生成。
- **建议学习资料类型**：OWASP LLM Top 10、注入防御实践。
- **对应项目实验**：P06 Wiki 生成注入测试。
- **掌握证明**：注入测试用例及防御通过记录。

### 24. 成本和延迟优化
- **为什么需要**：rerank、图检索、LLM 调用都花钱花时间，路由的合理性要量化。
- **建议学习资料类型**：推理成本估算、缓存策略文章。
- **对应项目实验**：P04/P08 延迟与成本记录。
- **掌握证明**：各链路延迟/成本表。
