# P00-L 资料理解、问题建模与 RAG 思维建立（学习桥接阶段）

## 状态

IN_PROGRESS（2026-09-01 设立）

> 定位：不改变主路线（P00→P01 顺序不变），是进入 P01 前的必要学习桥接，属阶段门。
> 1～2 周，不写业务代码，不建向量库。设立依据：用户决策 2026-09-01。

## 目标（完成后能做什么）

- 用自己的话解释主要资料类型分别做什么；
- 说出资料之间可能存在的工程关系；
- 解释一个问题需要什么证据；
- 判断一个问题是精确检索、组合检索还是跨文档追溯；
- 说明为什么某个问题可能需要图；
- 识别资料中的不确定性、冲突和版本风险；
- 为后续 RAG 设计提出自己的假设。

## 步骤

1. **深读 6 问**：从问题池选 6 个代表题（1 参数/IDS + 1 验收测试 + 1 方案/会议决策 + 1 跨文档 + 1 冲突 + 1 资料不足）。**先自己读证据，不看 LLM 解释**（证据定位可用 `scripts/extract_anchors.py`）。每问填一张学习卡（模板：`docs/learning/question-notebooks/LEARNING_CARD_TEMPLATE.md`）。
2. **画第一张领域关系图**：人工，不建机器图谱。每条关系标注"显式（有编号/引用/时间证据）还是推测"。骨架：需求/接口→方案设计→验收试验→结果结论→总结报告；会议纪要穿插各环节。
3. **RAG 问题地图**：6 问整理成"问题→需要的知识→难点→第一选择→是否需要图"表（模板见 `docs/learning/retrieval-problem-map.md`）。
4. **知识沉淀**：`knowledge-log.md` 记录 ≥5 条"我原来以为→资料实际显示→技术含义→假设→验证方法→对路线的影响"。
