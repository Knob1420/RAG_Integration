## 背景与决策记录（用户裁定，2026-09-06）

语料存在六类相似关系（用户提出三类 + 探测补全）。裁定规则：

1. **副本**（内容全等，含微差）：J≥0.995 → 组内标主从，从副本不进索引。
   主副本优先级：归档编号件 > 正题目录/根目录 > 盖章目录 > 外发目录；
2. **盖章 PDF 导出**（盖章目录 pdf ↔ 同基名 docx）：docx 为主（结构富：章节链/标题/原生表）；
3. **版本族**（J 0.5~0.99）：不去重，全部保留进索引，P01-004 标 `doc_family`/`effective_version`；
4. **同名不同内容 / 部分重叠**：非重复，无动作。

## 实现中的实测校准

- **指纹空白归一**：PDF 提取的空格插入/块合并会大量打断 5 字符指纹（同一文档 C 从 0.9+ 掉到 0.3），指纹计算前剥全部空白；
- **副本线 0.995**：试验大纲对 3 字符差实测 J=0.9995（副本），最近版本对 0.911（程控 9.1↔9.2）——两线之间无样本，阈值安全；
- **盖章导出线 C≥0.7 + 三信号叠加**（盖章目录 + pdf↔docx + 同基名）：版本族（0.911）可以比格式导出对（≈0.79，提取噪声所致）更相似，单靠相似度无法区分两类，必须叠加目录/格式信号；
- **多抓出一组精确重复**：环境试验报告（归档↔外发，J=1.000）——初测漏掉，空白归一后现形。共 7 组 9 份全等从本 + 3 份盖章导出从本；
- **未达导出线的盖章 pdf 如实保留**：说明书 V1.0 docx（7.4K 字）与盖章 pdf（12.3K 字）内容实质不同（pdf 为更多内容的修订版），C<0.7 不标从，两份都进索引——宁多录不静默丢内容。
