### 开始设计前十问回答

1. **为什么不能所有文件用同一种解析器？** 同一解析器无法同时处理"有文本层的 PDF、整页图像、OOXML 结构、二进制 .doc、网格数据"五种物理形态；强行统一（如全部转 txt）会丢掉标题层级、表格结构、sheet 划分——而这些恰是切分与溯源的原料（P00-L 学习门结论）。
2. **为什么 PDF 扩展名不足以决定路线？** .pdf 可能是数字版（可直提）、扫描版（无文本层需 OCR）、混合版（页级分流）。路线由**页级双信号**（chars/页 + 最大图像覆盖率）决定，扩展名只做第一道分流。
3. **为什么 OCR 不能只检查"是否生成了文字"？** OCR 可以生成"文字"但全是乱码/丢中文/漏表格——生成≠正确。须查 cjk_ratio、乱码率、密度 vs 图幅、表格行列守恒、编号字段抽检五项（见 routing R3 质量门）。
4. **WPS ZIP 路径问题在哪一层解决？** 解析管线**第一站统一修复**（临时副本重写条目名），不在各解析器内散修——docx 和 xlsx 共用，原始文件不动，修复动作可审计。
5. **为什么中文 .doc 默认不用 antiword？** 实测 antiword 输出 cjk_ratio 仅 0.06（中文静默丢失）；"看似成功的残缺输出"比失败更危险。LibreOffice 转 docx 为正路，antiword 不作兜底。
6. **为什么 Excel 不能逐行拼接成文本？** 逐行拼接丢失多行表头、合并单元格语义、sheet 边界和隐藏行列——行数据失去"哪列是什么"后无法判读（Q-006/Q-013 学习卡的直接教训）。必须按 sheet+逻辑区域切并展开表头。
7. **为什么 mtime 不能直接当 document_version？** 表内版本字段（sheet 最后修订时间/修订表/文件名 V1.0）才是文档自述版本；mtime 只是文件系统时间，解压/拷贝即失真（本批 mtime 曾全为解压日）。两者在 schema 中永久分离。
8. **为什么每个解析元素都要 source_id + 位置？** 引用回链、删除传播、版本过滤、评测归因全部依赖溯源链；无 source_id 的元素是孤儿数据，删除某资料时无法清理（DATA_GOVERNANCE 硬要求）。
9. **Golden Sample 验证解析什么、不验证什么？** 验证：结构还原、溯源正确、路由正确、质量门、防回归。不验证：问答对错（P03 评测集职责）、语义质量、图片内容。
10. **哪些失败必须阻断进索引？** 五类（quality-requirements 阻断表）：扫描页空文本、.doc 转换丢中文、OCR 乱码、无表头表格行、无 source_id 元素——共同点：**静默的错比显式的失败更危险**。
